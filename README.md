# Siddharth Sharma — portfolio

Personal site for Siddharth Sharma: engineer, co-founder of Everything Fine, Technical Head at Shramik Rojgar Private Limited.

Built with Next.js (App Router, TypeScript). Design takes its layout cues from kartikdhawan.in and its colours from the Everything Fine palette:

| Name | Hex | Use |
| --- | --- | --- |
| Jalebi orange | `#F26B1D` | Ventures band, highlights, primary accents |
| Chai cream | `#FFF4E3` | Light theme ground |
| Kadak ink | `#2B1A12` | Text, dark theme ground |
| Pista green | `#8DB580` | "Live" markers |
| Mithai pink | `#F28DB2` | The dot in the name, text selection (sparingly) |

## Run it

```bash
npm install
npm run dev
```

## Edit content

All copy, projects and links live in [`src/content/site.ts`](src/content/site.ts). Fill in `links.linkedin`, `links.instagram` or `links.resume` there and they appear automatically.

- Photos: `public/images/`
- Project screenshots: `public/work/` (captured from each live site)
